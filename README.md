# Tactical Combat AI — RimWorld 1.6

**Status: experimental source prototype; not compiled or tested in RimWorld 1.6.**

A Harmony-based NPC combat AI prototype for non-player humanoid factions, including raiders and allied groups.

Features under development:
- Field treatment of wounded same-faction pawns
- Moving downed allies to safer ground
- Retreat extraction using the game's existing `Kidnap` carrier job for same-faction casualties
- Ranged covering fire using the vanilla combat-wait behavior
- Cover-to-cover advances and nearby team target coordination

**Requires:** RimWorld 1.6, Harmony (`brrainz.harmony`), and a build against the game's `Assembly-CSharp.dll` and Unity assemblies.

This repository contains source code only. **Do not treat it as a compiled or verified release.** Use a disposable save for testing. See build instructions and test plans in the source package.

The source package was prepared in ChatGPT and is being uploaded to this repository.
